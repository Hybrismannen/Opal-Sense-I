# The Opal — Editorial Operations

OPAL SENSE I is the archive. The Opal is the publication.

## GitHub roles

**Projects:** The editorial planning board for priorities, assignments, source review and publishing.

**Issues:** Atomic research, editorial, verification and development tasks.

**Wiki:** Living reference pages, terminology, house histories, regional indexes and citations.

**Repository files:** Versioned magazine articles, machine-readable catalogues, source registries and application code.

## Workflow
Intake → Sourcing → Research → Fact-check → Draft → Edit → Published → Review.

## Editorial rules
Every shoe and garment is a separate object. Do not compare unrelated items unless explicitly requested. Treat model identity, quality, status, technology, condition and price as independent dimensions. Link claims to traceable sources, date fast-changing information and label unknowns clearly.

This repository is public: keep private shopping receipts and unlicensed images out of it.
