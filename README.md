# OPAL SENSE I [OSI´]
## THE OPAL — A Living Archive of Fashion, Culture & Design

**The Opal** is a long-form fashion magazine, object catalogue, and globally oriented research library. **OPAL SENSE I** is the system preserving the knowledge, provenance and publication history behind it.

> Clothing is never only clothing.

### Privacy and rights
This is a **public repository**. Personal purchases, private seller information and third-party pictures without appropriate reuse rights are deliberately excluded. Each shoe is treated as an independent object; cross-item comparisons are optional editorial analysis, never automatic.

The system is organised as **Identity → Context → Object → Evidence → Edition**.
