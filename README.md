A source-driven personal fashion magazine and reference collection spanning garments, shoe engineering, global fashion scenes, designers, brands, lineages, traditions and cultural history.

### Publishing standard
Separate sourced fact, interpretation, market observation and unverified claims. Every object gets its own identity and documented provenance. Keep personal receipts, private shopping information and images without rights out of this public archive.
